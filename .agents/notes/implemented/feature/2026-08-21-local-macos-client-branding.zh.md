# Agent Note: 本地 macOS 客户端品牌

Status: implemented

[English](2026-08-21-local-macos-client-branding.md) | 中文

## Problem

本地 macOS 应用嵌入普通 Web 构建；其侧边栏回退身份包含 `DSH Local Build` 与提交号，空会话主视觉区还带有产品预览版徽标。这项对外服务身份适用于外部开发浏览器，却不符合已安装应用所要求的身份。

## Decision

原生包装层在文档结束时安装一个只作用于主框架的 `WKUserScript`。它把精确匹配的侧边栏回退文案改为 `DeepSeek Harness`，隐藏同组的七位十六进制版本号，把任一语言的空会话标题改为 `简哥 · 探索未知之境`，并隐藏任一语言的预览版徽标。`MutationObserver` 只处理新增或变更的文本节点，因此 React 重新挂载侧边栏或空会话主视觉区时会再次应用品牌文案。

这些替换只存在于包装层的 `WKWebView` 中。回环服务、其构建产物以及在外部浏览器中打开的同一页面均保留上游身份。

## Alternatives considered

**修改共享 Web 客户端文案。** 未采用，因为该方案会替换所有浏览器部署的上游开发构建及预览版身份，而本次需求只适用于已安装的 macOS 应用。

**定位生成的 CSS Module 类名。** 未采用，因为重新构建 bundle 会改变这些选择器。精确可见文案与结构同级检查可以经受仅样式重建；当上游文案变化时，它也会保持不匹配，而不会改动无关内容。

## Consequences

已安装应用会显示指定的侧边栏名称与空会话标题，不再暴露构建版本号或预览版徽标。外部浏览器仍会标明开发构建及预览生命周期。如果上游更改了任一被匹配的源文案，就需要更新包装层的匹配列表；无法匹配的文案会保持原样，不会修改无关元素。
