# Agent Note: Home Agent 侧栏层级

Status: implemented

[English](2026-09-25-home-agent-sidebar-v2.md) | 中文

## Problem

在空白会话首页，五个 Agent 身份控件原先位于 Workspace 浏览器下方，并以轻内嵌辅助面板呈现；侧栏收起时它们还会消失。过长的名称和职责说明让这组入口更像次要说明，而不像容易发现的工作入口。

## Decision

空白会话首页的侧栏顺序是：新会话、AI 团队导航、Workspace 与 Session 浏览，最后是固定在底部的设置。展开时，AI 团队导航显示五个纵向按钮，每项含 42px 角色标记、短本地化名称、展示状态和克制的选中态。侧栏收起为 56px 轨道时，五个入口仍以 34px 角色标记显示，并提供本地化名称与状态提示。团队使用导航 landmark；每个按钮仍提供完整 Agent 名称和职责作为辅助技术可读名称。选择入口仍只改变首页 Hero 的展示身份；非空 Session 中不显示该组，也不会选择运行时 Agent、启动任务或改变 Session 状态。本决策取代 [Home Agent 视觉选中注记](2026-09-24-home-agent-visual-selection.zh.md)中的位置与可见名称决定；其中仅用于展示的状态约定仍然有效。

## Alternatives considered

**保留位于 Workspace 浏览区下方的内嵌面板。**其位置较低且采用卡片样式，会降低五个工作身份的可发现性，并让它们看起来像辅助信息。

**在每个 Session 中都显示 Agent 入口。**当前选择只改变空白首页的 Hero；在非空 Session 中显示会让用户误以为这是一个并不存在的执行控制。

**在每行保留完整英文名与职责说明。**这些文本挤占纵向列表空间；短本地化名称和可见状态更容易扫读，而辅助标签仍保留完整身份与职责。

**侧栏收起时隐藏全部 Agent 入口。**这会让主要首页入口在窄侧栏中不可用；紧凑角色标记和提示名称可以保留可发现性，而无需展开侧栏。

## Consequences

Agent 团队入口位于 Workspace 浏览之前，并在两种侧栏宽度下保持可选。它比原来的内嵌面板占用更多纵向空间，因此 Workspace 与 Session 浏览器使用剩余的弹性区域。该组仍是首页展示控制，不承担运行时 Agent 调度。现有吉祥物资产仍受软件包复用许可限制。

## Testing

侧栏行为测试固定入口顺序、本地化名称、不创建 Session 的选择行为、非空 Session 中的隐藏行为，以及收起轨道上的五个可访问控件；组合侧栏快照固定展开与收起两种呈现。
